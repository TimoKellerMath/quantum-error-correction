# tropidist certification of [[480,16,26]] (board entry 480-16-26)

tropidist (B. Cheng, N. Guo, F. Pan, arXiv:2611.08247; github.com/Fanerst/tropidist at commit b03ec2d4077f, the commit the qLDPC board pins for its tropidist certificates) certified the minimum distance of the [[480,16,26]] two-block group algebra code over C12 x Dic5 exactly on both sides: d_X = d_Z = 26, status exact, lower bound = upper bound = 26, with a returned vector of weight 26 on each side (rechecked independently of the tool).

- Problems: the board's css-sides encoding. For d_Z: H = H_X and L = a basis of 16 X-logical representatives (`inputs/480-16-26.Z.H.mtx`, `inputs/480-16-26.Z.L.mtx`); for d_X the mirror. Input hashes in `inputs/MANIFEST.json`.
- Run: `python -m cdist --matrices H.mtx L.mtx --threads 16 --time-limit 172800` per side, on a 64-core machine with 16 threads per side, 10 November 2026; wall times 5185 s (X) and 5474 s (Z). Records: `records/rec_X.json`, `records/rec_Z.json`; run data and progress: `logs/` (home paths shortened to `~/`).
- Labelling. The inputs use the element numbering of our representation-theory line (`inputs/480-16-26.hx`, `.hz`, witnesses `.wX`, `.wZ`), which differs from the numbering of the board entry `codes/480-16-26.json` (the convention of the board's entries 720-16-36 and 960-24-38). `perm.json` gives a qubit permutation pi (pi[i] = input qubit of entry qubit i), found with nauty canonical labellings of the Tanner graphs. `python3 check_perm.py PATH/codes/480-16-26.json` checks that pi maps the rows of H_X and of H_Z of the entry onto the rows of the inputs. A qubit permutation preserves the minimum distance, so the verdicts hold for the entry.
